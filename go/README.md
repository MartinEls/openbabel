# SMILES3D - Native Go Pipeline

This directory contains a standalone, native Go implementation of a cheminformatics pipeline that converts SMILES strings into 3D molecular structures (XYZ format).

It replaces the previous approach of using an `os/exec` wrapper around the `obabel` C++ binary, providing a safer, embedded solution for basic molecular modeling directly within Go.

## Features

- **SMILES Parser (`smiles/`)**: Parses a subset of SMILES strings (CHNO atoms, chains, branches, rings, aromaticity) and automatically infers implicit hydrogens.
- **Molecular Representation (`mol/`)**: Core data structures for Atoms and Bonds.
- **3D Builder (`builder/`)**: Generates initial, non-overlapping 3D coordinates using a rule-based distance geometry approach combined with a spring-model untangling step.
- **UFF Optimizer (`uff/`)**: A simplified Universal Force Field (UFF) implementation that optimizes the 3D geometry using steepest descent, handling bond stretching, angle bending, and Van der Waals interactions.
- **XYZ Writer (`xyz/`)**: Outputs the final molecular coordinates in the standard `.xyz` format.

## Usage

You can run the pipeline directly using `go run main.go <SMILES string>`.

### Example 1: Ethanol

```bash
cd go
go run main.go CCO
```

```bash

```

## Testing

To run the unit tests (which verify the parser and coordinate generation across various standard molecules):

```bash
cd go
go test ./... -v
```

## Note on Stereochemistry

This simplified pipeline currently focuses on 2D connectivity and 3D relaxation. It gracefully ignores stereochemical markers (`@`, `@@`, `/`, `\`) in the SMILES input.
